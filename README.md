# APK Dependency Graph Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов Alpine Linux (apk).

Готовые средства (менеджеры пакетов, библиотеки) для получения зависимостей **не используются**.

Вариант №28 (без этапа 4).

## Описание

CLI-приложение, которое:

1. Принимает параметры через аргументы командной строки.
2. Получает информацию о прямых зависимостях пакетов Alpine Linux (apk).
3. Строит полный граф зависимостей (с транзитивностью) алгоритмом DFS **без рекурсии**.
4. Учитывает максимальную глубину анализа.
5. Фильтрует пакеты по подстроке в имени.
6. Корректно обрабатывает циклические зависимости.
7. Поддерживает тестовый режим с файлом описания графа.
8. Генерирует текстовое представление графа на языке Graphviz (DOT).

## Параметры командной строки

| Параметр | Описание | Обязательный |
|----------|----------|--------------|
| `--package` / `-p` | Имя анализируемого пакета | Да |
| `--repo` / `-r` | URL репозитория или путь к файлу тестового репозитория | Да |
| `--test` / `-t` | Режим работы с тестовым репозиторием (флаг) | Нет |
| `--depth` / `-d` | Максимальная глубина анализа зависимостей (по умолчанию 10) | Нет |
| `--filter` / `-f` | Подстрока для фильтрации пакетов | Нет |

## Установка и запуск

### Требования

- Python 3.10+
- Только стандартная библиотека

### Примеры

```bash
# Этап 1 — параметры
./run.sh -p A -r data/test_repo_simple.txt -t --stage1

# Этап 2 — прямые зависимости
./run.sh -p A -r data/test_repo_simple.txt -t --direct-only

# Этапы 3+5 — граф + Graphviz
./run.sh -p A -r data/test_repo_simple.txt -t -d 5

# С фильтром
./run.sh -p A -r data/test_repo_simple.txt -t -f E

# Цикл
./run.sh -p A -r data/test_repo_cycle.txt -t
```

Результат можно сохранить:

```bash
./run.sh -p A -r data/test_repo_simple.txt -t > graph.dot
# При наличии graphviz:
# dot -Tpng graph.dot -o graph.png
```

## Формат тестового репозитория

```
PACKAGE: DEP1 DEP2 DEP3
```

Пакеты именуются **большими латинскими буквами**.

## Алгоритм

- **DFS без рекурсии** (явный стек + раскраска вершин).
- Отслеживание серых вершин для обнаружения циклов.
- Ограничение по максимальной глубине.
- Фильтрация пакетов по подстроке.

## Сравнение с штатными инструментами

Для реальных пакетов Alpine результаты могут отличаться от `apk info -R` / `apk graph` по причинам:

1. Инструмент строит транзитивное замыкание самостоятельно.
2. Не учитываются `provides`, конфликты и виртуальные пакеты.
3. Версии и архитектура разрешаются упрощённо.
4. В тестовом режиме используется искусственный граф.
